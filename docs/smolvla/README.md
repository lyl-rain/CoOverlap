# SmolVLA 端侧调度与 LIBERO 验证

CoOverlap 在 Jetson AGX Orin 上使用 SmolVLA 验证了 CUDA Graph 推理、固定周期调度和 KV 发布，并在 LIBERO 中独立验证了同步仿真接口。以下是 2026 年 11 月 20–22 日已完成实验的结果。

## CUDA Graph 推理

固定 SO100 输入、模型计算、十步去噪和 50 动作输出。从内存中的观测进入预处理，到完整动作块完成后处理并返回 CPU，eager 参考的 Host 中位数为 **750.56 ms**（20 次）。启用 Expert 单步 CUDA Graph 后，再捕获包含完整 KV 构建的 prefix Graph。在两轮同输入对照中，加入 prefix Graph 后的 Host 中位数为 **110.958 / 110.637 ms**，同轮配对中位数缩短 **61.718 / 62.891 ms**（每轮 10 对）。eager 是独立参考批次。

## 102 ms 固定周期调度

固定模型计算、输入和每周期 Expert 工作。每 102 ms 释放一个周期，每两个周期请求一次完整 KV 刷新。两轮按相反顺序测量三个方案，每方案每轮 200 周期、100 次刷新，总计 **1,200 周期和 600 次完整刷新**。各组通过数值和硬件性能资格。原工程筛选线为每组动作和周期分别最多超限 2/200。

| 方案 | 完整 KV 发布所在周期（从请求起算） | 两轮动作超限 | 两轮周期超限 |
| --- | --- | --- | --- |
| S1 · 整图串行 | 第 2 个 | 0/200、0/200 | 100/200、100/200 |
| S2 · 分块串行 | 第 2 个 | 0/200、0/200 | 0/200、1/200 |
| E · 分区与边界归还 | 第 1 个 | 0/200、0/200 | 0/200、0/200 |

E 在合法文本子图边界查询 Expert 完成事件，已完成时使用全 GPU 执行尚未提交的 VLM 尾图，否则保留原分区。两轮合计 **132 次归还、68 次回退**，回退样本均纳入统计。完整 KV 才发布，Expert 在一次十步去噪内读取固定版本。

相对通过工程筛选的 S2，E 的完整 KV 发布配对中位差为 **−78.732 / −78.537 ms**，逐请求相对缩短的中位数为 **45.230% / 45.222%**。刷新请求所在周期的 Expert 动作交付配对中位数晚 **22.639 / 22.837 ms**。每轮 99 份可配对的 KV 均提前一个周期首次消费，S2 在各轮末尾的一份窗内未见消费。这是既定固定负载与冻结方案的系统结果。另一次同配额边界归还对照的发布净提前为 4.288 / 4.257 ms，独立于上述系统对照。

配对按同轮、同刷新请求匹配。发布时间从计划释放到 Host 完整 KV 发布，动作时间从计划周期释放到 Host 动作交付。相对缩短先逐请求计算，再取中位数。首次消费统计保留未观察项。

曾测试的选择性等待方案使动作提前，但完整发布两轮分别晚 3.359 / 4.091 ms，首次消费周期未变。

## LIBERO 同步闭环

使用 LIBERO checkpoint 在同一仿真任务、初态和种子上对照参考路径与适配路径。两次运行均在 10 个静置动作后，以 **75 个策略动作**成功完成任务。双观测 A→B→A 数值资格的 **24/24 项**检查逐位一致。验证覆盖观测身份、模型输入和输出、动作下发以及首次应用该动作的 MuJoCo 积分时间边界。

同步实验只覆盖该任务与种子。另测的异步协议两臂均在 400 动作处达到上限且未成功，性能资格未通过。
